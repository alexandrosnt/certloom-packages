# certloom packages

apt and dnf repositories for certloom-agent, published by the certloom release
workflow. Setup: docs/runbooks/install-packages.md in the certloom repository.

Packages and repository metadata are signed with this key:

    C43A8AC970C276971D4889C294E7B14DD2231CF4

The public key is `gpg.key` in this repository. Check the fingerprint against
docs/verify-release.md in the certloom repository before trusting it.
